LangTechDepot

Help

Almost everything that goes wrong is one of the things below. Find yours, or skip to asking a person.

It says registration failed, the token is unknown, or it has already been used

A token works once, on one machine. If you have already run the installer successfully on this computer, you are done — there is nothing more to do. For a second computer, or after a reinstall, request a new token. Also check nothing extra came along when you copied it: a stray space or a line break at the end will fail.

The black window closed before I could read it

The installer waits for you to press a key before its window closes, so any error stays on screen. If the window vanished anyway, your antivirus may have stopped it (see below). It can also happen if the zip window was closed while the installer was still running. Run it again and leave the zip window open until it finishes; or unzip the download first — right-click it → Extract All → Extract — and double-click setup-langtechdepot.bat in the folder that opens.

Windows says “Windows protected your PC”

Click More info, then Run anyway. This appears for anything downloaded from the internet that has not been through Microsoft’s paid signing programme.

It says something went wrong extracting the installer

The download was damaged or cut short. Delete it, download langtechdepot-windows.zip again, and double-click the setup-langtechdepot.bat inside the new one.

It says it could not get Syncthing

The installer gets Syncthing through winget, Windows’ own app installer. Some machines do not have it, and some networks block it. Download Syncthing yourself from syncthing.net/downloads (the Windows 64-bit archive) and take syncthing.exe out of it. This is the one case where the LangTechDepot zip must be unpacked first: right-click it → Extract All → Extract, put syncthing.exe in the folder that opens, beside setup-langtechdepot.bat, and double-click the .bat there. It uses the copy it finds beside it.

My antivirus deleted the installer

Some antivirus products remove scripts they have not seen before. Restore it from the quarantine list, or ask whoever manages the machine to allow the folder. Tell us if this happens — it is worth knowing which product.

The list of folders never appears

The installer waits for the list to arrive from the depot before it can show it, so give it two or three minutes. If it still does not come, open the Syncthing page — on Windows, double-click Am I up-to-date, and advanced management in your LangTechDepot folder; on Linux, use the address the installer printed at the end — and look at Remote Devices on the right. If the depot is listed but disconnected, this machine cannot reach the server — usually a firewall or a captive portal. If it is not listed at all, registration did not complete: run the installer again. The same token still works, because it was never accepted.

On Linux, if the terminal says the computer is missing yad, the installer stopped before doing anything: it needs yad to show the folder window. Whoever looks after the machine can add it (on Ubuntu, Debian or Mint, sudo apt install yad); then paste the command again. You will not need a new token.

I left a folder unticked and want it now

On Windows, double-click Change my Assets in your LangTechDepot folder (or run the installer again) and click Also display ignored folders; tick it and click Apply. On Linux, run the installer command again and do the same.

I deleted a file by accident

Nothing is lost, and nothing propagates. Your folders are receive only, so Syncthing simply flags the difference and offers a Revert local changes button, which brings the file back from the server. The same is true if you edit one.

Can I run it again?

Yes. The installer is safe to run as many times as you like — it checks what is already in place rather than redoing it. You only need a new token for a different computer, or if LangTechDepot’s settings on this one were wiped.

Can I copy the files to another machine on a memory stick?

Yes. What lands on your disk is ordinary files and folders, not a special format — copy the tree and carry it. Machines in the same office also sync directly from each other, so only the first one to get a file pulls it over the long link.

Asking a person

Write to depot@langtech.cloud, or reply to the email your token arrived in — both reach the people who run the depot. Two things make a fast answer much more likely:

  • whether you are on Windows or Linux, and
  • the exact text of any error, copied from the window rather than described. A photo of the screen is fine too.
