Windows: four steps

Do them in order. Nothing here needs administrator rights, and nothing is left half-installed if you stop partway — you can pick up again at any point.

  1. Step 1Get your token
  2. Step 2Download
  3. Step 3Run it
  4. Step 4Pick your folders
1

Get your token

Fill in the short form on our server. A token comes back — a long password that works once, on this one computer.

Get my token Opens depot.langtech.cloud. The token page there has a Copy button and a link straight back to step 2.
2

Download the installer

One small file. Your Downloads folder is a fine place for it.

Download for Windows langtechdepot-windows.zip · under 10 KB
Unzip it before you open anything inside it. Right-click the downloaded file → Extract All → Extract. Double-clicking straight out of the zip preview window looks like it works and then fails: Windows unpacks only the one file you clicked, and the installer needs both of them side by side.
3

Double-click run-setup-langtechdepot.bat

A black window opens and does the work. When it asks for your token, paste it in — right-click inside the window, or press Ctrl+V — and press Enter.

If Windows says “Windows protected your PC”: click More info, then Run anyway. That warning appears for anything downloaded from the internet that has not been through Microsoft’s paid signing programme.
If it says it cannot find Syncthing: this machine has no winget. Download Syncthing for Windows from syncthing.net/downloads, put syncthing.exe in the same extracted folder as the other two files, and double-click the .bat again.
4

Pick the folders you want

A web page opens at 127.0.0.1:8384. Within a minute or two the offers appear at the top — one for each part of the library. Click Add on the ones you want and ignore the rest. Files arrive under C:\Users\you\LangTechDepot.

What the names look like: each offer is named for the part of the library it carries. On offer at the moment: Win_everything_en (everything a Windows user needs, in English), French_win and Indonesian_win (language editions of the same), Android_dev_win (tools for building Android apps), Android_apps (apps to copy onto a phone or tablet) and Documentation. Take Win_everything_en if you are not sure.
Seeing only a few? The library is still being moved onto this system a folder at a time, so not all of it is on offer yet. You do not need to register again or do anything else — new folders appear in this list by themselves as they arrive.

That is the whole setup. Syncthing starts with your computer from now on and keeps those folders current by itself. The folders only ever receive — nothing on your machine is sent anywhere.

Setting up a second machine? Start again at step 1: each machine needs its own token.
Stuck? The help page covers what usually goes wrong. If the black window showed an error, copy that text — it is what lets us fix things quickly.
